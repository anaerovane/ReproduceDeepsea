# Figure 3 result files on Hugging Face

Browse or download the published outputs:

- [Hugging Face Figure 3 outputs](https://huggingface.co/aer0vane/reproduce_deepsea/tree/main/experiment/Figure3/outputs)
- [GitHub Figure 3 code, plots, and documentation](https://github.com/anaerovane/ReproduceDeepsea/tree/main/experiment/Figure3)

Restore the published files to the `fuxian3` project root:

```bash
hf download aer0vane/reproduce_deepsea --include "experiment/Figure3/outputs/**" --local-dir .
```

## Uploaded files

The 28 files total about 27.48 GB. The two core model outputs are `ours_effects.npy` and `pretrained_effects.npy` (13,643,135,936 bytes each); these are actual ref/alt DeepSEA inference results and are not available as direct downloads elsewhere. `variants.tsv` preserves the row order used by both matrices. The folder also contains the four out-of-fold prediction tables, extracted CADD/GWAVA/FunSeq2 score tables, final AUC tables, and compact manifests/verification records.

## Not uploaded

`sequences.npy` is a 1.86 GB derived cache. It can be rebuilt from the public Supplementary Tables 5/6 and hg19 reference FASTA listed in the [project download guide](../../DOWNLOAD.md). The 40 fold-level `.npz` prediction caches and classifier JSON files can be regenerated by rerunning evaluation from the published effect matrices and code; they are not required for Figure 9 or Supplementary Figure 7.

The pretrained and locally trained model weights are stored separately in the existing Hugging Face model paths and are not duplicated here.
